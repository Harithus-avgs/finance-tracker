# Finance Tracker

A small, client-side personal finance tracker designed for Indian Rupees. It runs as a static web app with no server, database, build step, or account required.

## Run it

Download or clone the project and open `index.html` in a modern browser. Your records are saved in that browser's local storage. Use the download and upload buttons in the app header to export or restore a JSON backup.

## Features

- Dashboard, monthly calendar, transaction history, and recurring transactions
- Accounts, savings buckets, investments, budgets, categories, debts, and credit score tracking
- Planning tools, monthly reports, and forecasts
- Dark and light themes
- JSON backup export and import

## Data and privacy

This app has no backend and does not sync data between browsers or devices. Data stays in the browser's local storage unless you export a backup. Clearing browser data can remove your records, so keep backups somewhere safe. Imported and exported backups contain sensitive financial information; do not publish them or share them publicly.

The repository excludes the author's local `data.json` and `Data backup.txt` files. These are personal data snapshots and are not needed to run the app.

## Current scope

This version is a single-user, local browser app. It does not currently provide Google sign-in, cross-device synchronization, or an AI chatbot. Those can be considered as later project work.
